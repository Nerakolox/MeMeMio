### `humanName` 是数组，不是字符串

```json
"humanName": ["白圣女与黑牧师", "塞西莉亚"]
```

作品名、角色名、社群叫法**平铺进同一个数组**——它们在检索里是同一种东西（用户可能打的字）。区分留给[别名层](../../../joint-tasks/2026-09-13-meme-lexicon.md)的数据模型。

空数组 `[]` 的含义是**库主人看过且认不出**，不是「还没填」。全集 16 条是这个状态，它们构成别名层收益的天花板。

**`api/scripts/eval.ts` 要注意：名字 query 是多目标的。** `塞西莉亚` 对应 `161` / `723` / `768` 三张，`kipfel` 对应两张，`魔裁` 对应两张。按「一条 query 一个正确答案」写会算错 `recall@5`。

### `acceptAlso`：给「两种都对」留的位置

```json
"expect":     { "emotions": ["假笑", "得逞", "满足"] },
"acceptAlso": { "emotions": ["开心", "害羞"] }
```

`acceptAlso` 里的词，模型标了**既不算命中也不算污染**，直接从两个分母里剔除。

只在**人工判定两种读法都成立**时用，不是拿来给模棱两可的标注开后门的。现在全集只有 `698` 一条。一张连人都要想一下的图，拿它当非黑即白的判据，量出来的是噪声不是模型能力；但如果什么都往这里塞，「语气微妙」这一档就等于没测。

`api/scripts/eval.ts` 必须实现这个字段，漏了的话 `698` 会被算成一次假的污染。

> ⚠️ **扫一眼点头 = 没有校对。**
>
> 如果通读一遍觉得「差不多都对」，那多半是因为它读起来很像你会写的东西 —— AI 起草的文本天然有这个效果。`395` 那条就是活证据：它读起来毫无破绽，意思完全反了。至少要真的改掉一部分才算过。**改完把 `status` 改成 `reviewed` 并 bump `version`。**

## 词表合规是硬性的

`expect` 和 `acceptAlso` 里的 `emotions` / `scenes` / `tags` **必须全部落在 [`shared/vocab/vocab.json`](../../../shared/vocab/vocab.json) 里**，否则「词表合规率」这个指标从基准这一侧就已经是脏的。

改完跑一遍：

```bash
python -c "
import json
m=json.load(open('docs/fixtures/eval/manifest.json',encoding='utf-8'))
v=json.load(open('shared/vocab/vocab.json',encoding='utf-8'))
E,S=set(v['emotions']),set(v['scenes'])
T=set(v['tags']['subject'])|set(v['tags']['style'])
bad=[(i['file'],src+'.'+k,x) for i in m['items'] for src in ('expect','acceptAlso')
     for k,ok in (('emotions',E),('scenes',S),('tags',T))
     for x in (i.get(src) or {}).get(k,[]) if x not in ok]
print(bad or 'OK', len(m['items']))"
```

> 起草这份草稿时，这个检查抓出了 **10 处违规**，全部是把 `讨好` `看戏` `撒娇` `心虚` 这类词填进了 `scenes`。
>
> **这不是手滑，是词表设计暴露出的问题**：情绪和场景的边界并不自明，「讨好」既像一种情绪也像一个使用场合。起草者对着词表都会填错，模型只会错得更多。记为 [词表任务](../../../joint-tasks/2026-09-13-vocab-v1.md) 的输入。

## 选出来的 30 张证实了两件事

跑完 `manifest.json` 的统计，两个此前只是推测的判断变成了实测：

| 观察 | 数字 | 后果 |
|---|---|---|
| `tags.subject` 全部是同一个值 | **动漫角色 30/30** | 标签过滤那一路在这个库里**没有区分度**，三路混合实际退化成两路。这不是选图偏差，是库的真实构成 |
| `tags.style` 也高度集中 | 动漫 25/30 | 同上 |
| 但 `无文字` / `带字幕` 有信号 | 15 / 9 | 这一对是 `tags` 里唯一还有用的：它直接告诉你这张图**该走哪条检索通路** |

第一行动摇的是 [SPEC §9.10](../../../spec/09-decisions.md) 三路混合的前提，交给 [词表任务](../../../joint-tasks/2026-09-13-vocab-v1.md)；第三行说明 `style` 里的这组词值得单独保住，不要在精简词表时一起砍掉。
