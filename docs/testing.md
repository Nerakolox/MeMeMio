# 测试

## 1. 原则

**测那些「坏了但不报错」的地方。** 编译器和类型系统已经挡掉了一类问题，测试不需要重复它们。

本项目有四处属于「坏了会静默」，测试的重点全在这里：

| 地方 | 坏了的表现 | 不测就发现不了 |
|---|---|---|
| 软删过滤 | 删掉的图又出现了 | ✅ 不报错 |
| `assertCanMutate` | 别人能删你的图 | ✅ 不报错 |
| 词表校验 | 库里出现词表外的标签 | ✅ 不报错 |
| 归一化后的 L2 | 余弦相似度悄悄不对，搜索变差 | ✅ 完全静默 |

最后一条最隐蔽：截断向量后忘记重新归一化，**代码正常运行、接口正常返回、搜索结果只是"有点不准"**。没有测试就只能靠评测集在几周后发现。

## 2. 分层

| 层 | 用什么 | 测什么 |
|---|---|---|
| 单元 | vitest | 纯函数：pHash / Hamming、向量截断归一化、词表校验、拒绝形态判定、RRF 融合 |
| 集成 | vitest + 真 Postgres（testcontainers 或本地 db） | 访问层、权限、去重、队列 |
| 端到端 | 少量，覆盖导入和搜索两条主链路 | 前后端接起来没断 |

**集成测试用真 Postgres，不用 mock 或 sqlite。** 本项目重度依赖 `pgvector`、`pg_trgm`、`bit_count`、`FOR UPDATE SKIP LOCKED`——这些全都无法 mock，mock 掉之后测的就不是真实行为了。

## 3. 必须有的测试

这份清单不是穷举，是**不写就算没做完**的那些：

**软删**
- 每个列表 / 详情接口对软删记录都返回空 / `NOT_FOUND`
- 搜索三路（OCR、标签、向量）**各自**都过滤软删——这三路是分别写的，容易只改一路
- 收藏了一张后来被软删的图，收藏列表里不出现它；恢复后又出现

**权限**
- 非上传者非管理员删除 → `FORBIDDEN`
- 非上传者**编辑** → **成功**（这是有意的不对称，[SPEC §3.3](../spec/03-auth-permission.md)，容易被"顺手补一个检查"改坏）
- 管理员删除任意图 → 成功
- `assertCanMutate` 的三个 `action` 各测一遍

**去重**
- 同字节文件第二次上传 → `exact_dup`，不产生第二条记录
- Hamming 距离为 0 但内容不同的两张图 → **两条记录都能建**（这条测的是 `phash` **没有**唯一约束，见 [SPEC §9.7](../spec/09-decisions.md)）
- 近似命中的图 `tagStatus` 保持未打标，不进队列

**向量**
- 2560 维截断到 1024 后，L2 范数为 1（误差 1e-6 内）
- 维度 < 1024 的配置被拒绝保存

**词表**
- 模型返回词表外标签 → 重试一次 → 仍失败则 `AI_REFUSED` 路径
- 人工编辑提交词表外标签 → `VALIDATION_FAILED`（不能只挡模型，见 [SPEC §4.5](../spec/04-vocabulary.md)）

**AI 失败**
- 三种拒绝形态各触发一次降级，用 [`responses/`](fixtures.md) 里的真实样本
- 主副通道都失败 → `tagStatus = needs_manual`，**图仍然入库**

## 4. 不测什么

| 不测 | 原因 |
|---|---|
| 真实 AI 调用 | 慢、要钱、不确定。质量靠[评测集](eval.md)，不靠单测 |
| R2 真实上传 | 用接口签名的单测 + 一条端到端覆盖 |
| ffmpeg 抽帧的具体帧内容 | 测「抽出了 N 帧且都是 PNG」，不测像素 |
| 前端样式 | 没有回归价值 |
| Hono 路由本身能不能跑 | 那是框架的测试 |

## 5. 评测集不是测试

[评测集](eval.md)回答的是「**准不准**」，测试回答的是「**对不对**」。

两者不能互相替代：评测集的结果是分数不是断言，会随模型和提示词浮动，**不能进 CI 门禁**——一次供应商侧的模型静默升级就会让它红，而那不是代码坏了。

评测集手动跑，结果记在[评测集任务](../joint-tasks/2026-09-13-eval-set.md)里；测试进 CI，红了就是坏了。

## 6. 测试数据

用工厂函数，不写 SQL 种子文件，见 [fixtures.md](fixtures.md)。

每个测试自己建自己要的数据，**不依赖全局种子**。共享的种子数据会让「这个测试为什么过 / 为什么挂」需要翻到另一个文件才能回答。
