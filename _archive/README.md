# 归档

放**已经不是现行依据、但删掉会丢失来历**的文档。

归档不是回收站。这里的每一份都回答同一个问题：**「当时为什么这么决定」**。三个月后有人提出一个看起来更好的方案时，答案通常在这里。

## 规则

- **只增不删。** 归档后的文件不再修改，包括错别字
- 文件名带日期：`YYYY-MM-DD-主题.md`
- 归档时在文件顶部或本 README 里注明**被什么取代了**
- 现行文档引用归档内容时，要说清楚「这是历史版本」
