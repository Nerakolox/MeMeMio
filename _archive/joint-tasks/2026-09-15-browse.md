# 浏览页：`GET /memes` 与 `/browse` 前端

**状态：`done`** · 创建 2026-09-15 · 验收关闭 2026-09-15

## 为什么

搜索页只处理关键词查询（三路融合，不分页）。用户还需要一条独立的浏览路径：按情绪、场景、标签、动图标志、收藏状态等条件筛选全库，结果无限滚动。这是两条设计上完全不同的路径——混用会导致分页行为冲突，见 [SPEC §6.3](../../spec/06-endpoints.md)。

`api` 目前没有 `GET /memes` 路由，web 无法联调，因此升级为跨端任务。

## 做完的标准

- [x] `GET /api/v1/memes` 上线，支持 `emotions`/`scenes`/`tags`/`isAnimated`/`favorited`/`uploader`/`tagStatus`/`cursor`/`limit` 参数
- [x] 软删记录不出现在结果中
- [x] `tagStatus` 参数只有本人或 admin 可用，其他人传该参数返回 `FORBIDDEN`
- [x] `GET /api/v1/memes/{id}` 上线，返回单条 Meme（含 `favorited` 字段）
- [x] Web `/browse` 页面：左侧筛选器 + 右侧图片网格，筛选条件全部走 URL query string
- [x] 游标翻页：滚动到底自动加载下一页，追加到列表末尾
- [x] 收藏/取消收藏：乐观更新，失败回滚
- [x] 空状态、加载中（骨架）、错误状态三态完整

## 两端各自做什么

### api 端

**涉及的 SPEC：** §6.3.2（浏览接口参数与分页）、§5.2.6（Meme 对外表示）、§5.4（收藏字段）、§3.3（权限矩阵，含 tagStatus 限制）、§3.4（软删过滤强制要求）、§1.3（游标分页约定）；错误见 §2，响应约定见 §1.1。

1. **`GET /api/v1/memes`**：
   - 参数：`emotions`、`scenes`、`tags`（可重复传，多值 AND）、`isAnimated`（布尔）、`favorited`（`true` 时只返回当前用户收藏的）、`uploader`（`me` 或用户 id）、`tagStatus`（仅本人或 admin 可用）、`cursor`（首页不传）、`limit`（默认 40，最大 100）。
   - `tagStatus` 参数：非本人且非 admin 时返回 `FORBIDDEN`（`SPEC §3.3`）。
   - **所有结果必须过滤 `deleted_at is null`**，这是硬性要求，见 [SPEC §3.4](../../spec/03-auth-permission.md)。
   - 每条结果包含 `favorited` 字段（当前登录用户是否收藏）。
   - 响应：`{ items: Meme[], nextCursor: string | null }`。游标不透明，客户端不解析。
   - 按 `created_at desc` 排序，cursor 基于此字段实现。

2. **`GET /api/v1/memes/{id}`**：返回单条，含 `favorited`，软删记录返回 `NOT_FOUND`。

3. **数据层**：新增 `src/data/memes.ts`，`listMemes(params, actor)` 和 `getMemeById(id, actor)` 两个函数。软删过滤和 `favorited` 聚合在数据层统一处理，不散落在 handler 里。

4. **回填本文档**：完成后在「api 端验收」小节回填实测情况。

### web 端

**涉及的 SPEC：** §6.3.2（接口参数）、§5.2.6（字段定义）、§5.4（收藏乐观更新语义）；错误展示见 §2。

**依赖：** api 端需先完成 `GET /memes` 接口，web 端才能做完整联调。骨架可先行，但必须等接口上线才算完成。

1. **`src/lib/api.ts` 新增**：
   - `Meme` 类型（字段来自 §5.2.6）
   - `fetchMemes(params)` 函数，参数类型与接口参数一一对应，响应 `{ items: Meme[], nextCursor: string | null }`
   - `toggleFavorite(memeId, favorited)` 函数（`PUT`/`DELETE /memes/{id}/favorite`）

2. **`src/routes/browse.tsx` 新建** `BrowsePage`：
   - 筛选条件**全部放 URL query string**，参数名与接口参数名一致，不做二次映射（见 `agents/rules/state-navigation.md` §1）。
   - 筛选选项从 `src/lib/vocab.ts` 读（`emotionOptions`、`sceneOptions`、`tagOptions`），不硬编码。
   - `tagStatus` 筛选项只在 `user.role === 'admin'` 或筛选自己的图时显示（前端判断，后端也会拒绝）。
   - 游标分页：初次加载取第一页，滚动到底时用 `nextCursor` 追加下一页。`nextCursor` 为 `null` 时不再触发加载。
   - 收藏按钮：乐观更新（本地先翻转 `favorited`），接口失败时回滚，编辑标签/删除**不做**乐观更新（见 `agents/rules/state-navigation.md` §8）。
   - 空状态、加载骨架（与结果卡片同尺寸）、错误状态三态完整，错误状态展示 `requestId`。

3. **`src/App.tsx`**：注册 `/browse` 路由（套 `RequireAuth`），header 导航加「浏览」入口。

4. **`src/styles.css`**：追加 browse 页布局样式，只写结构性 CSS（flex/grid、尺寸、间距、overflow），不写颜色、字体、阴影等装饰性样式（见 `web/AGENTS.md §5`）。

5. **回填本文档**：完成后在「web 端验收」小节回填实测情况，说明在哪个浏览器实测过筛选、翻页、收藏三条路径。

完成时间：2026-09-15

**新增 / 修改的文件：**
