# 导入体验

流程与接口见 [SPEC §6.2](../../../spec/06-endpoints.md)，SSE 事件见 [SPEC §1.4](../../../spec/01-http.md)。

## 1. 入口不止一个

- 多选文件上传
- 拖拽文件夹（**递归扫描**）
- 剪贴板 Ctrl+V 粘贴
- ZIP 包
- 手机端从相册选择

全部汇入同一条流程，**不为某个入口另做一套**。

## 2. 上传直传 R2

```
POST /imports 拿预签名 URL → 前端直传 R2 → POST /imports/{id}/commit → 订阅 SSE
```

**文件字节不经过 `api`。** 不要为了"简单"改成 POST 到后端再转发——那会让 Node 进程被大文件拖垮。

并发上传要有上限（建议 3–5 个），一千张图同时发会把浏览器和网络打爆。

## 3. 进度必须具体

「导入中 237/1000」是不够的。用户要能看出**卡在哪一步**：

```
上传中     237 / 1000
处理中     198 / 237
已入库     180
跳过重复    15
待你确认     3
```

导入一千张要跑很久，**没有分阶段的进度用户会以为卡死了**。

## 4. 不弹中途确认框

> ⚠️ **这是本文最重要的一条。**

上千张图导入时每张重复都弹窗，体验会崩掉。所以：

- 精确重复（`exact_dup`）→ **静默跳过**，只计入摘要
- 近似重复（`needs_review`）→ **攒进待确认队列，不阻塞导入**
- 导入结束后统一处理队列

**队列里只有 1 条时，把它呈现成即时弹窗。** 同一个接口、同一套数据，只是单条时换个呈现形式——单张上传的场景因此天然得到即时反馈，**不需要为它另写一套代码**。

见 [SPEC §6.2.3](../../../spec/06-endpoints.md) 与 [§9.7](../../../spec/09-decisions.md)。

## 5. 待确认队列长什么样

左右并排，让用户自己判断：

```
┌─ 你传的这张 ─┐   ┌─ 库里已有的 ─┐
│              │   │              │
│   [预览]     │   │   [预览]     │
│              │   │              │
│ 1024×768     │   │ 800×600      │
│ 320 KB       │   │ 180 KB       │
└──────────────┘   │ @alice 上传  │
                   └──────────────┘
        Hamming 距离：3

  [跳过]  [仍然导入]  [稍后再说]
```

三个动作缺一不可。**「稍后再说」不是可有可无的**——用户在导入一千张后不一定有精力当场判断三十个近似重复，强迫他现在决定只会让他随便点一个。

条目跨批次累积，`GET /imports/reviews` 拿全部。超过 7 天未处理的会被服务端连同暂存文件清理，**界面上要说明这一点**。

## 6. 摘要报三个数

```
已入库 982 张，跳过 15 张完全相同的文件，3 张待你确认
```

三个数分开报。「成功 982、失败 18」会让用户以为出了问题，而跳过重复是**正常且有价值**的结果——那是省下来的 AI 调用。

## 7. 失败要具体

不要只说「失败 37 张」。至少区分格式不支持 / 文件损坏 / 超大 / 超配额。

单文件失败**不中断整批**——它作为 SSE `item` 事件的 `reason` 出现，不是 HTTP 错误。

超配额是例外：剩余文件全部标记失败，`done` 事件会说明。界面要**显示剩余配额**，不是只说「超了」。

## 8. SSE 断线

- 在 `useEffect` 清理函数里 `close()`
- **断线重连后用 `GET /imports/{batchId}` 补齐**，中间漏掉的事件不会重发
- `done` 后主动关闭

导入跑十分钟时断线是常态，不是边缘情况。**只靠 `EventSource` 自动重连会丢事件**，进度条会卡在某个数字上不动。

## 9. 导入期间应用保持可用

导入是异步的。用户应该能切到搜索页继续用，**不要把导入做成一个模态全屏页面**。

进度用一个可收起的浮层或状态栏呈现，切走再回来还能看到。

## 10. 没配模型也能导入

不配视觉模型时导入**照常进行**，图片入库为 `tagStatus = pending`。

界面提示「已入库，尚未打标」+ 一个指向设置页的链接，**不是错误、不用红色、不阻断上传**。见 [SPEC §2.4](../../../spec/02-errors.md) 的 `AI_NOT_CONFIGURED`。
